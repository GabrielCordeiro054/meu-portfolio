# Meu Portfólio Pessoal

## Sobre o projeto

Este projeto foi desenvolvido como atividade do curso técnico de Desenvolvimento de Sistemas EaD da ETEC Conselheiro Antônio Prado.

O objetivo foi criar um portfólio pessoal para apresentar um pouco sobre mim, minha formação, meus conhecimentos e os projetos que desenvolvi durante meus estudos.

## Tecnologias utilizadas

- **HTML5:** utilizado para estruturar as informações da página.
- **CSS3:** utilizado para personalizar as cores, os espaçamentos e a aparência do site.
- **Bootstrap 5:** utilizado para facilitar a organização da página e adaptar o layout a diferentes tamanhos de tela.
- **Git e GitHub:** utilizados para controlar as versões e armazenar o projeto.

## Organização do portfólio

O site está dividido nas seguintes seções:

- **Perfil:** uma breve apresentação pessoal.
- **Formação:** informações sobre minha trajetória educacional.
- **Projetos:** apresentação de atividades desenvolvidas durante o curso.
- **Habilidades:** conhecimentos adquiridos em programação e tecnologia.
- **Contato:** formas de entrar em contato e acessar meu GitHub.

## Funcionalidade adicional

Como funcionalidade extra, adicionei um efeito de animação nos cartões da seção Projetos.

Quando o usuário passa o mouse sobre um cartão, ele se movimenta um pouco para cima e recebe uma sombra, destacando o projeto.

Essa funcionalidade foi desenvolvida utilizando CSS, por meio da propriedade `transform` e do seletor `:hover`.

## Como executar

Para visualizar o portfólio no computador, basta baixar os arquivos do repositório e abrir o arquivo `index.html` no navegador, com acesso à internet para carregar o Bootstrap.
